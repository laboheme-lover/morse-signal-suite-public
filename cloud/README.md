# 無料オンライン試用版の配備

Streamlit Community Cloudで同じ公開リポジトリから2つのアプリを作成します。

| 項目 | 音声 | 光 |
|---|---|---|
| Repository | laboheme-lover/morse-signal-suite-public | 同左 |
| Branch | main | main |
| Main file path | cloud/audio_app.py | cloud/optical_app.py |
| Python | 3.11 | 3.11 |

依存はエントリーポイントと同じフォルダのrequirements.txt、OS側はルートのpackages.txtです。無料枠では休止や資源制限があります。常時稼働の保証はありません。

公開画面はアップロード専用で、サーバーの任意ファイルパスを入力できません。音声・動画は50 MB・120秒以内、動画はフルHD相当・60fpsまでです。動画の一時ファイルと光処理結果ファイルは約30分後に削除します。認識結果はブラウザのセッションにも残るため、共有端末では画面を閉じてください。光解析は最大5分で終了します。

アップロードはクラウド側で処理されます。機密情報を含む音声・動画はアップロードしないでください。モデルと認識規則はPC採用版と同じですが、無料サーバーでの速度や同時利用数は別途確認が必要です。

配備には所有者のStreamlitへのログインとGitHub連携が必要です。公開URLは配備成功後にルートREADMEへ記録します。ソースをpushしただけではオンライン公開完了ではありません。
