## 実行

プロジェクト `morse-ai` を作業フォルダとして使用します。

```powershell
.\.venv\Scripts\python.exe -B -X utf8 phase7_real/evaluate.py
.\.venv\Scripts\python.exe -B -X utf8 phase7_real/report.py
```

`evaluate.py` は既存の `results` がある場合に停止します。評価済み結果の上書きは行いません。`report.py` は保存済み結果から資料を再作成します。新しいデータでの評価は別の出力先・評価計画として追加してください。

元のモデル、音声、過去の正解文・出力等244ファイルのハッシュ不変を検証しました。旧合成Test全3,022件も評価前後で不変でした。40件×4モデルの全160文章を再採点し、保存済み結果と一致することを確認しています。共通のモード処理・正規化・分割・編集距離の既存8テストに成功しました。

CSVはUTF-8 BOM付き、テキストとJSONはUTF-8です。各番号フォルダに参照文、モデルごとの文章・区間予測・編集対応を保存しています。`prediction_agreement.csv` のルール一致率や予測確率は、正解率としては扱いません。
