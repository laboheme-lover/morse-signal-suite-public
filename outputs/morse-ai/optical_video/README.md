# 動画の光モールス認識：最小構成

2026-09-22。固定カメラで撮影した固定光源の点滅を、指定領域の明るさから解析する試作版です。音声モデルの採用判断とは独立した機能で、M1〜M4・既存CNNを使用せず、重みを変更しません。実撮影動画の精度は未評価です。

## 起動と操作

3方式を一度に比較し、進捗確認・中止・ZIP保存ができるようになりました。[一括比較と中止の手順](一括比較と中止の手順.md)を参照してください。

プロジェクト直下の `start_video.cmd` をダブルクリックし、ブラウザーで http://127.0.0.1:8502/ を開きます。PC上の既存仮想環境を使用します。終了は起動した画面でCtrl+Cです。音声アプリを起動中なら、サイドバーに追加した「動画の点滅認識」ページからも利用できます。

1. AVIまたはMP4を選びます。まず「合成サンプルを使用」で試せます。
2. プレビュー時刻を動かし、光源が点灯しているフレームを表示します。
3. 左X・上Y・幅・高さを入力し、緑の枠で光源を囲みます。元の動画の画素座標です。サンプルはX=60、Y=40、幅=40、高さ=40です。
4. 解析する開始・終了時刻を選びます。初期値は全動画です。
5. 「解析する」を押します。短点長の自動推定ができない場合はOFFにして秒数を入力します。
6. 本文、明るさ／しきい値／点灯判定のグラフ、符号と文字の一覧を確認します。文字区間を選ぶと、その開始フレームを表示します。
7. 必要に応じて短点長・しきい値・文字間隔を手動調整します。変更すると以前の結果は無効になります。
8. TXT、文字CSV、詳細JSONをダウンロードします。JSONには輝度列、点灯消灯の時刻、入力SHA-256、ROI、設定が含まれます。

括弧は国際モールスへの切替信号として扱い、本文には表示しません。未知符号や点灯途中の切断は□と理由を表示します。明暗反転にも対応します。確率やAIの正解率は表示しません。

## 処理と判定条件

動画をフレーム単位で読み、ROI内の平均グレースケール輝度を測定します。明るさの5・95パーセンタイル間の幅が15未満なら判定を停止します。自動しきい値はその幅の35%と65%に分け、点灯状態の細かな往復を抑えます。ノイズ除去によるフレームの削除・補間は行いません。

短点長の自動推定は点灯時間を短い群と長い群へ分け、中央値の比が2.3〜3.7となる場合に採用します。一種類しかない点滅などは曖昧なので手動値が必要です。通常の文字境界は短点長の2倍以上の消灯で区切り、長い語間はイベントに保存します。本文へ自動的に空白を挿入しません。

短点が5フレーム未満では本文を空にし、候補を参考結果として表示します。5〜8フレームでは警告します。これらは試作版の保守的な条件であり、実撮影で検証済みの性能保証ではありません。

フレーム時刻が単調増加し、固定fpsと整合することを確認します。時刻を取得できない動画や可変fpsらしい動画は拒否します。この検査だけで、あらゆる可変fpsを検出できるという保証はありません。最大200 MiB、横1920×1080／縦1080×1920、60fps、10分です。数値列とプレビューのみを保持し、全フレームをメモリに保持しません。

## 開発用実行

プロジェクト直下で実行します。

```powershell
.\.venv\Scripts\python.exe -m pip install -r optical_video/requirements.txt
.\.venv\Scripts\python.exe -B -m optical_video.synthetic
.\.venv\Scripts\python.exe -B -m unittest optical_video.test_video -v
```

`evaluate_synthetic.py` は評価フォルダーが既にある場合、上書きせず停止します。依存追加はOpenCV headless 4.10.0.84だけで、既存NumPyは変更していません。[配布元・ライセンス情報](https://pypi.org/project/opencv-python-headless/4.10.0.84/)。動画は外部送信せずローカル処理します。
